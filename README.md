# AI Football Coach

Use AI to help football coaches plan training sessions and improve their teams.

The [Docusaurus](https://docusaurus.io/) docs site lives in the [`docs/`](docs/) directory.

## Requirements

- [Node.js](https://nodejs.org/) 26 (see [`docs/.nvmrc`](docs/.nvmrc))

## Installation

```bash
cd docs
npm install
```

## Local development

```bash
cd docs
npm start
```

Starts the docs site at [http://localhost:3000](http://localhost:3000). Most changes reload automatically.

## Build

```bash
cd docs
npm run build
```

Generates static files in `docs/build`. Preview them with:

```bash
cd docs
npm run serve
```
