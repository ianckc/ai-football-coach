# Frontend

The TanStack Start app in `frontend/` is the web UI for coaches. It is a TypeScript Vite app with file-based routing. Today it serves a minimal root page that identifies the product; auth, API calls, and domain features are not wired yet.

By default the dev server listens on [http://localhost:3000](http://localhost:3000). The `backend/` service defaults to port `8000`, and the docs site to `3001`.

## Requirements

- [Node.js](https://nodejs.org/) 26 (see [`frontend/.nvmrc`](frontend/.nvmrc); same as the docs site)

## Install

From the repository root:

```bash
cd frontend
npm install
```

## Run locally

```bash
cd frontend
npm run dev
```

Starts the app at [http://localhost:3000](http://localhost:3000). The root route renders **AI Football Coach**.

## Tests

```bash
cd frontend
npm test -- --run
```

`quality-tests` in the software factory runs this same command.

## Quality gates

Biome handles lint and format. TypeScript covers typecheck.

```bash
cd frontend
npm run format:check   # Biome format (CI / factory)
npm run format         # Biome format --write (local fix)
npm run lint           # Biome lint
npm run typecheck      # tsc --noEmit
```

`quality-static` runs `format:check`, `lint`, and `typecheck` when those scripts are present. GitHub Actions (`.github/workflows/frontend.yml`) enforces the same on PRs that touch `frontend/`, plus `npm test -- --run` and `npm run build`.

## Layout

| Path | Role |
|------|------|
| `frontend/package.json` | Scripts (`dev`, `test`, `build`, `lint`, `format`, `format:check`, `typecheck`) and TanStack Start deps |
| `frontend/biome.json` | Biome lint + format config |
| `frontend/.nvmrc` | Node 26 for local and CI |
| `frontend/vite.config.ts` | Vite + `@tanstack/react-start` plugin |
| `frontend/src/routes/__root.tsx` | Document shell / head |
| `frontend/src/routes/index.tsx` | Root (`/`) page |
| `frontend/src/router.tsx` | Router factory |
| `frontend/tests/` | Acceptance-style Vitest checks for the scaffold |
