# Frontend

The TanStack Start app in `frontend/` is the web UI for coaches. It is a TypeScript Vite app with file-based routing. Today it serves a minimal root page that identifies the product; auth, API calls, and domain features are not wired yet.

By default the dev server listens on [http://localhost:3000](http://localhost:3000). The `backend/` service defaults to port `8000`, and the docs site to `3001`.

## Requirements

- [Node.js](https://nodejs.org/) 22+ (Node 26 works; same major family as the docs site `.nvmrc`)

## Install

From the repository root:

```bash
cd frontend
npm install
```

## Run locally

```bash
cd frontend
npm run dev
```

Starts the app at [http://localhost:3000](http://localhost:3000). The root route renders **AI Football Coach**.

## Tests

```bash
cd frontend
npm test -- --run
```

`quality-tests` in the software factory runs this same command.

## Typecheck

```bash
cd frontend
npm run typecheck
```

`quality-static` runs `tsc --noEmit` when a `typecheck` script is present (there is no frontend lint script yet).

## Layout

| Path | Role |
|------|------|
| `frontend/package.json` | Scripts (`dev`, `test`, `build`, `typecheck`) and TanStack Start deps |
| `frontend/vite.config.ts` | Vite + `@tanstack/react-start` plugin |
| `frontend/src/routes/__root.tsx` | Document shell / head |
| `frontend/src/routes/index.tsx` | Root (`/`) page |
| `frontend/src/router.tsx` | Router factory |
| `frontend/tests/` | Acceptance-style Vitest checks for the scaffold |
