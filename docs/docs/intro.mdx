# Introduction

**AI Football Coach** helps football coaches plan training sessions and improve their teams with AI.

## What this docs site covers

This documentation site is the home for product guides, concepts, and reference material as the project grows.

## Backend API

The Rust service in `backend/` already exposes HTTP endpoints (health check and account creation). See **[Backend API](./backend-api)** for request/response contracts.

## Software factory

Work is delivered through a Swamp Club TDD factory (GitHub Issues on a Project board, Cursor agents at gates). See **[Software factory](./software-factory)** for setup and step-by-step commands.

## Getting started (this docs site)

From the `docs/` directory (this Docusaurus site):

1. Install dependencies with `npm install`.
2. Start the docs site locally with `npm start`.
3. Open [http://localhost:3000](http://localhost:3000) to preview changes.

Edit markdown files under `docs/docs/` to update these pages — the development server reloads automatically.
